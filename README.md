# Fretworks
A Guitar Fretboard Visualizer -- making soloing easy!

## Getting Started

### Installation

```bash
git clone https://github.com/adamtruth/fretworks.git . && \
cd fretworks && \
make build
```

#### Make
Ubuntu: `sudo apt-get install make`
MacOS: `brew install make`
Arch: `sudo pacman -S make`
Windows: `idk`

#### Docker
For contributions use [Docker](https://www.docker.com/get-started/)!
